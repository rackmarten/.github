# RackMarten

Small, practical open-source tools that grew out of running a self-hosted
homelab on Proxmox. Each one solves a problem I actually had, is used daily,
and is kept simple enough to read in an afternoon.

## Projects

| Project | What it does |
| --- | --- |
| [lxc-configurator](https://github.com/rackmarten/lxc-configurator) | Modular, idempotent Bash provisioning for Proxmox LXC containers |
| [server-kit](https://github.com/rackmarten/server-kit) | Fastify 5 + TypeScript building blocks for the backend of a small self-hosted web app |
| [ui-kit](https://github.com/rackmarten/ui-kit) | Vue 3 + Vuetify 3 building blocks for the frontend of a small self-hosted web app |
| [eslint-config](https://github.com/rackmarten/eslint-config) | Opinionated ESLint 9 flat config + Prettier config for TypeScript and Vue 3 |

More are on the way as they get cleaned up for public use.
